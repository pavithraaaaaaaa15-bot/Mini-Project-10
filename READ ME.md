# XOR Neural Network from Scratch

A two-layer neural network built with NumPy only, trained with backpropagation and gradient descent to learn the XOR function.

## Why XOR?
A single-layer perceptron cannot learn XOR because the classes are not linearly separable. A hidden layer with a nonlinear activation solves it.

## Setup
```bash
pip install -r requirements.txt
```

## Run
```bash
python xor_nn.py
```
